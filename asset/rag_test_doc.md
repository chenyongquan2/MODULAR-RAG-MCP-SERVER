1. **RMA**：Return Merchandise Authorization，返修/换货授权编号。  
2. **SLA**：Service Level Agreement，服务等级协议。  
3. **“标准件”**：指按 CML《标准件目录》供货的通用部件（不含定制件）。

5. **“Pro 版”**：指产品命名中带 “Pro” 的型号（例如：Aster-7 Pro）。

# 4. 固件与兼容性（用于版本约束测试）

## 4.1 Aster-7 系列固件策略

- Aster-7（标准版）支持固件：FW 1.x  
- Aster-7 Pro 支持固件：FW 2.x  
- **不允许**将 FW 2.x 刷入标准版（会导致设备无法启动）。

## 4.2 已知问题（KB）

**KB-A7-014：Aster-7 标准版在 FW 1.8.0 上存在 BLE 断连问题**  
- 现象：高干扰环境下每 15～30 分钟断连一次  
- 影响范围：Aster-7（标准版），FW 1.8.0  
- 解决方案：升级到 **FW 1.8.2** 或更高版本（仍为 1.x）

# 6. RMA 流程（用于多步推理与引用）

## 6.1 提交材料

客户发起 RMA 需提供：
1. 订单号或发票号  
2. 产品序列号（SN）  
3. 故障描述（尽量包含复现步骤）  
4. 若为 Orchid-GW：请附上系统导出的 `diagnostics.zip`

## 6.2 审核与时效（SLA）

- 工单受理：**1 个工作日**内响应  
- 初步诊断：**3 个工作日**内给出结论  
- 维修周期：备件齐全情况下 **7～10 个工作日**

## 6.3 RMA 编号格式

RMA 编号格式：`RMA-YYYYMM-####`  
示例：`RMA-202603-0042`

## 7.1 日志与数据
